# Nanopore Allele-Specific Methylation Workflow 

This workflow performs methylation analysis for sample `OTC3` using:
- `minimap2` for ONT alignment
- `clair` (v2.1.1) for SNP calling
- `vcftools` for VCF filtering/subsetting
- `whatshap` for SNP phasing
- `nanopolish` for per-read methylation calling
- `nanomethphase` for haplotype methylation phasing and DSS-based DMA

All tools are configured to run through Singularity images.

## Expected inputs

Edit `config/samples.tsv` and `config/config.yaml` before first run.

Required:
- FASTQ (merged ONT reads) per sample
- FAST5 directory per sample

xing

Reference is downloaded automatically from `reference_url` into `reference_fasta` and indexed with `samtools faidx`.

## Run

```bash
snakemake --use-singularity --cores 24
```

For cluster/HPC execution, add your profile/executor flags as usual.

Output is under `results/`.

Stdout/stderr logs are written under `logs/` (for example, `logs/OTC3/nanopolish_index.log`).

## Separate Fast Clair Benchmark (XIST only)

To compare multiple historical Clair3 versions without touching the long-running methylation pipeline,
use the separate workflow:

```bash
snakemake \
  -s workflow/clair_benchmark_xist.smk \
  --configfile config/clair_benchmark.yaml \
  --use-singularity \
  --cores 24 \
  --nolock
```

Notes:
- This benchmark workflow reuses existing `results/{sample}/alignment/{sample}.sorted.bam` and reference files.
- It calls variants only in the configured XIST interval to run quickly.
- It writes only under `results/{sample}/benchmarks/clair_xist/`, `work/benchmark_clair_xist/`, and `logs/benchmark_clair_xist/`.
- Ranking output is `results/{sample}/benchmarks/clair_xist/{sample}.ranking.tsv`.
- Edit candidate Clair3 tags in `config/clair_benchmark.yaml` (`versions:` list, e.g. `v0.1-r12`).
- Per-version calling uses manual `apptainer/singularity exec docker://docker.io/hkubal/clair3:<tag>` inside the rule (to support Snakemake builds that do not allow dynamic `container:` URLs).

## Build custom images (NanoMethPhase)

Because `quay.io/biocontainers` images are not available for `nanomethphase`, this repo includes a GitHub Actions workflow:

- `.github/workflows/build-custom-tool-images.yml`

It builds and pushes to Docker Hub:

- `nanomethphase`: local custom multi-stage Dockerfile at `docker/nanomethphase.Dockerfile`

The custom NanoMethPhase image keeps compile dependencies in a build stage and ships a smaller runtime stage with:
- `nanomethphase` + `whatshap` (Python venv)
- `samtools` / `tabix`
- R + Bioconductor `DSS` (for `dma`)

Set these GitHub repository secrets:

- `DOCKERHUB_USERNAME`
- `DOCKERHUB_PASSWORD` (Docker Hub access token or password)

Then run workflow **Build Custom Clair3 and NanoMethPhase Images** via **Actions > Run workflow** (it builds the NanoMethPhase image used by this main pipeline).
After the first successful push, set your Docker Hub namespace in `config/config.yaml`:

- `containers.nanomethphase`

## Notes on defaults

- XIST region default is `chrX:73813879-73862026`
- SNP filtering currently applies only minimum QUAL (`snp_filter.min_q`).
- Clair model files are automatically downloaded/extracted to `resources/models/clair/` from `clair_model.source_url`.
- Current defaults use `quay.io/biocontainers/clair:2.1.1--0` with ONT model `122HD34.tar`.
- If any container tag is unavailable on your system, update `containers:` in `config/config.yaml`.
- VCF metric summaries (`QUAL`, `DP`, `AF`) are generated by `workflow/scripts/summarize_vcf_metrics.py`.
